# 组件审美审查

本次检查原有 44 个注册组件的源码与浏览器预览，删除 3 个重复条目，保留 41 个。调整了其中 27 个组件的材质、排版、交互或窄屏适配，另有 14 个保留现有实现。

取舍依据：用途是否独立、静态画面是否完整、动效是否服务内容、大小舞台是否都清晰，以及复制源码后能否独立使用。保留极简基础组件，同时收敛重复效果、刺眼辉光和不稳定的排版。

## 删除的条目

| 条目 | 判断 | 对应保留能力 |
| --- | --- | --- |
| 字符跳变 `hyper-text` | 与解码文字同为乱码从左到右还原，独立维护价值较低。 | 解码文字补充键盘聚焦、关闭挂载播放的选项，并稳定中西文字宽。 |
| 逐字错峰入场 `staggered-text-reveal` | 与文字显现的视口触发、模糊和错峰上浮高度重叠，放在滚动分类也容易混淆。 | 文字显现支持反复进视口播放；分字入场保留另一种裁切揭示机制。 |
| 流星描边按钮 `star-border` | 圆形旋臂无法贴合胶囊轮廓，光点多数时间被裁掉；与流光按钮用途重叠。 | 流光按钮重做连续尾光、静态细边和内高光，保留明确的点击反馈。 |

相应源码与注册项一并移除；搜索、详情页、提示词接口和索引继续由注册表自动派生。MCP 演示中的旧按钮名称也同步更新。

## 工程处理

所有视觉和交互参数同步到注册条目的设计要点。卡片注册拆分为 `cards/index.tsx` 与 `cards/surfaces.tsx`，保持原有顺序，并遵守单文件不超过 300 行、每层源码目录不超过 8 个文件的限制。

未增加运行依赖，保留 TypeScript 严格模式、Tailwind 与组件自包含机制。
